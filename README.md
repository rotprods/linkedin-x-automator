# LinkedIn · X Automator

**An AI agent engine that posts for you on X (Twitter) and LinkedIn — autonomously.** Researches every 4 hours, scores viral signals, writes the copy, generates the image, posts on its own and learns from results. From **0 to 100,000 followers**.

> 🎓 **For students:** this repo is a **self-installation kit**. You only need to paste ONE prompt into your Higgsfield Supercomputer — the agent handles the onboarding, installation and step-by-step setup.

## 🌐 Language / Idioma
- **[Español](README.es.md)** — guía completa en español
- **[English](README.en.md)** — full guide in English

## 🚀 Quick start for students
1. Create your account at [higgsfield.ai](https://higgsfield.ai) → **Supercomputer**.
2. Clone or upload this repo to your Supercomputer:
   ```
   git clone https://github.com/rotprods/linkedin-x-automator.git
   ```
3. Open a chat and paste the contents of **[`PROMPT-0-ARRANQUE.md`](PROMPT-0-ARRANQUE.md)**.

The agent runs a **9-question onboarding**, installs the skills and subagents, guides you through Slack setup and connecting your networks, schedules the crons, runs a **dry-run test**, and only posts after you give the **GO**.
